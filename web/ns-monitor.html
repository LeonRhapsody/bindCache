风险分级规则

无 ASN/国家数据时仅标记“元数据未知”，不会因猜测提升等级。

低风险

NS 减少、数量变化仍在原注册域，或同一 NS 的 IP 变化但 ASN 和国家均一致。

中风险

同一 NS IP 变更，且 ASN 或国家其中一项发生变化。

高风险

新增 NS 跨注册域；或同一 NS IP 的 ASN 和国家同时变化。

严重

NS 端点落入私网、回环、链路本地、多播或未指定地址空间。
