# Kimi 前端还原与正式功能实现清单

## 1. 实施原则

- `frontend/` 中的离线 React/Vite 源码是视觉、布局、文案和交互基准。
- 仿真数据只能用于开发降级预览，正式模式必须通过同源 `/api/v1/*` 接口读取 ClickHouse 和运行状态。
- 页面上的每个可操作控件必须满足以下三者之一：
  - 已连接真实接口并提供成功、失败、权限不足和加载状态；
  - 明确显示为只读或不可用，并说明缺失依赖；
  - 仅在开发仿真模式出现，并带有醒目的“仿真数据”标识。
- “缓存观测”“重复异常”“权威分歧”“实际影响”是不同证据状态。未完成拨测或权威验证时，不得在页面或告警中表述为已确认投毒。
- 前端使用 Hash 路由，确保刷新、浏览器前进/后退和 Go 单二进制静态托管均可用。

## 3. 统一数据模型

### 3.1 风险事件

统一事件必须包含：

- `id`、`type`、`domain`
- `level`：`critical/high/medium/low/recovered/unknown`
- `evidence`：`cache_hint/repeated/pending_verify/auth_divergence/impact_confirmed`
- `status`：`active/pending/confirmed/recovered/excluded/ignored`
- `first_seen`、`last_seen`、`duration_seconds`
- `observations`、`cluster_size`、`snapshot_id`
- `summary`、`change_fields`
- `affected_count`、`handler`、`opinion`

事件详情按需加载基线、当前端点、拨测、影响面、RR、时间线和告警，避免列表接口返回大对象。

### 3.2 四类场景扩展

- NS 变化：NS 集合、注册主域、地址、ASN、国家、保留地址和组内应答差异。
- NS 单一与冗余：单 NS、同 IP、同网段、同承载设施、冗余退化、唯一 NS 不可达；同 ASN 或同国家不单独判定为单点。
- 父子不一致：父区委派、子区权威、Glue、实际 A/AAAA、TTL/传播窗口、DNSSEC、逐 NS 权威应答。
- 黑名单：对象类型、匹配值、来源、版本、可信度、分类、生效/过期时间、原始描述、当前是否使用、白名单状态。

## 4. API 规划

### 4.1 只读查询

- `GET /api/v1/overview`
- `GET /api/v1/events`
- `GET /api/v1/events/{id}`
- `GET /api/v1/events/{id}/impact`
- `GET /api/v1/events/{id}/probe`
- `GET /api/v1/events/{id}/rr`
- `GET /api/v1/domains`
- `GET /api/v1/domains/{domain}`
- `GET /api/v1/probes`
- `GET /api/v1/alerts`
- `GET /api/v1/system`
- `GET /api/v1/settings`
- `GET /api/v1/session`
- `GET /api/v1/audit`

### 4.2 有副作用的接口

- `POST /api/v1/events/{id}/actions`：确认、忽略、限期白名单。
- `POST /api/v1/probes`：受限人工补测，不允许浏览器直接访问外部 DNS。
- `POST /api/v1/blacklists`：仅接受离线 CSV，校验格式、哈希、版本和有效期。
- `POST /api/v1/alerts/retry`。
- `PUT /api/v1/settings`：只写允许在线修改的配置，凭据仍由环境变量提供。

所有写接口记录操作人、时间、来源地址、对象、前值、后值与原因。
事件 JSON/CSV 由详情页基于当前已加载证据本地生成，不触发服务器状态变更。

## 6. 视觉与交互验收

- 桌面端按 1440px 基准逐页截图比较，重点检查侧栏宽度、卡片间距、表格密度、字体、颜色和图表比例。
- 在 1024px、768px 和 390px 验证断点；表格允许横向滚动，侧栏变为抽屉。
- 浏览器前进/后退必须只切换应用页面，不能退出系统。
- 筛选条件写入 Hash 查询参数，刷新后保持。
- 动画仅用于严重活动节点呼吸、恢复一次确认、新行一次高亮和系统异常点；卡片不循环运动。
- 尊重系统 `prefers-reduced-motion`，并保留页面内“减少动态”开关。
- 所有请求具备加载、空、部分证据、数据源异常、权限不足和失败重试状态。
